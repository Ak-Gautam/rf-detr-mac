# RF-DETR Mac Fork

This documentation set is intentionally minimal.

Use this repo if you want to run the retained Apache-2.0 RF-DETR Medium and Large models on Apple Silicon, with either:

- PyTorch on MPS
- MLX for local inference

Important links:

- [Technical notes](technical.md)
- [Local run guide](local.md)

This fork is based on [roboflow/rf-detr](https://github.com/roboflow/rf-detr). The original RF-DETR work belongs to the upstream authors and contributors. The Apple Silicon reduction and MLX port are the main additions in this fork.
